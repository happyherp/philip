# Project Instructions

## Workflow

When you are done with a task:

1. **Merge latest main** into your working branch (`git fetch origin && git merge origin/main`).
2. **Create a feature branch** with a descriptive name (e.g. `add-turnstile-bot-protection`).
3. **Commit** all changes with a clear commit message.
4. **Push** the branch to `origin`.
5. **Open a pull request** against `main`.

Never commit directly to `main`.
